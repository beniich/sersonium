SENSORIUM CAFM PRO — SITE VITRINE
=================================

Contenu :
- index.html : page vitrine complète en français
- style.css : design responsive, animations visuelles et mise en page
- script.js : menu mobile et année automatique
- assets/ : vos deux images de référence intégrées au site

MISE EN LIGNE SUR CPANEL
1. Téléversez le contenu du dossier (index.html, style.css, script.js et assets/)
   dans public_html/ ou dans le dossier racine du sous-domaine.
2. Vérifiez que le dossier assets est bien au même niveau que index.html.
3. Ouvrez votre nom de domaine.

PERSONNALISATION AVANT PUBLICATION
- Remplacez contact@votredomaine.com dans index.html par votre adresse e-mail.
- Remplacez les textes de présentation et les coordonnées selon votre entreprise.
- Les chiffres et mentions de disponibilité sont indicatifs et doivent être validés
  selon les capacités réellement déployées.
- Les références réglementaires ne constituent pas une certification.

Le site est statique : aucun serveur Node.js ou base de données n'est nécessaire.
